Airtel Money App

Project Description

This is a Python project that simulates an Airtel Money mobile money application. It was created for learning and practicing Python programming.

Features

- View account balance
- Send money
- Deposit money
- Withdraw money
- Reverse the last transaction
- View transaction history
- Change password
- logout option

Language Used

Python

Purpose

This project demonstrates the use of variables, conditional statements, loops, and linked lists in Python.
 It`s for the purpose of learning and nothingmore nothingless 

Disclaimer

This is an educational simulation, not an official Airtel Money application. It does not process real financial transactions.
